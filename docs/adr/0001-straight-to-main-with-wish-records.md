# Changes go straight to main; Wish Records replace PRs

During the live session, every working change is committed directly to `main` and pushed in the background. There are no branches or pull requests: speed and a jargon-free experience for the kids matter more than review gates, and the Team must never see or wait on code review. To keep things traceable, each Wish (or chain of Wishes touching the same feature) gets an English GitHub issue, a Wish Record, closed by the commit that delivers it. The Grown-up can use the triage labels afterwards to flag anything that needs cleaning up.
